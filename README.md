# Interactive SQL Playground

An interactive web-based SQL playground that allows users to write, execute, and analyze SQL queries directly in the browser.

## 🚀 Features
- SQL editor with syntax highlighting
- Real-time query execution (SQL.js)
- Query explanation in natural language
- Step-by-step execution breakdown
- JOIN visualizer
- Query history tracking

## 🛠️ Tech Stack
- HTML, CSS, JavaScript
- SQL.js (SQLite in browser)

## 🎯 Purpose
This project helps users understand SQL concepts through visualization and interactivity instead of just theory.
